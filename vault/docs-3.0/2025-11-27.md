## 信息的分类聚合

> 我觉得可以这样，评分阶段发给大模型，让它捎带返回分类，scored_articles中就包含分类，接下来的聚合就更好操作的。只需要预先提供几个分类，让大模型“选词填空”即可。

- 设计流程
  1. 采集阶段：RSSHub → collector-service → Kafka: raw_articles
  2. 评分阶段：ArticleScoringService (LLM) → Kafka: scored_articles (筛选7分以上)  *这里进行调整*
  3. 分类阶段：CategoryService (LLM) → 为每篇文章添加分类标签
  4. 聚合阶段：按分类分组，进行主题聚类
  5. 总结阶段：每组选择高质量文章，生成推文/日报框架
  6. 内容提取：爬取最终选定文章的详细内容
  7. 生成阶段：生成完整推文/日报
