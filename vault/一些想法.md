## **二、热度预测功能设计**  =》 网络视频热度

### **核心预测目标**
**24小时内可能爆发的技术话题**，例如：
- "Spring 6.2新特性讨论量激增→预测为下周面试热点"
- "某Java漏洞在知乎被频繁提及→预测为安全预警"

### **预测指标设计**
```java
// 输入特征（每秒更新）
- messageVelocity: 单位时间消息量增速（核心）
- interactionAcceleration: 互动量加速度（点赞/转发增速）
- sentimentPolarization: 情感极化度（方差）
- crossPlatformLag: 跨平台扩散延迟（知乎→掘金时间差）
- influencerDensity: 大V参与密度（万粉用户占比）
- keywordEmergence: 新关键词涌现频率（NLP提取）
```

### **预测模型选型**
**阶段1（本周）：线性回归**
- 方法：最小二乘法拟合近7天历史数据
- 输出：预测明日消息量
- 触发条件：预测值 > 历史均值 * 1.5

**阶段2（下周）：XGBoost**
- 数据：收集2周特征数据，标注"爆发/未爆发"
- 训练：本地CPU训练（1000样本足够）
- 输出：爆发概率（0-1）

**阶段3（1.5版本）：时间序列分解**
- 方法：STL分解（趋势+季节+残差）
- 识别：残差突增=异常事件=潜在热梗

## **四、数据流设计**

### **Topic划分策略**
```yaml
topic-discovery:      # 来自RSSHub/知乎热榜
  key: topic
  value: TopicDiscovery
  partition: 1        # 低频，单分区足够

question-details:     # 知乎问题详情+回答
  key: questionId
  value: QuestionAnswer
  partition: 3        # 按questionId哈希，保证同一问题的回答到同一分区

social-messages:      # 模拟/真实评论（主数据流）
  key: topic|source
  value: SocialMessage
  partition: 10       # 按topic分区，便于Streams聚合

analyzed-stream:      # AI分析后
  key: topic|source
  value: AnalyzedMessage
  partition: 10

topic-stats:          # 窗口聚合结果
  key: topic|window
  value: TopicStats
  partition: 10

hot-trend-prediction: # 预测结果
  key: topic
  value: TrendPrediction
  partition: 1

alert-events:         # 预警事件
  key: topic
  value: Alert
  partition: 1
```

### **消息结构演进**
```java
// 新增：富化消息（关联热榜）
public record EnrichedMessage(
    SocialMessage original,
    TopicDiscovery hotTopic,    // 关联的热榜信息
    Double relevanceScore       // 与热榜的相关度（0-1）
) {}

// 新增：趋势预测
public record TrendPrediction(
    String topic,
    Long predictTimestamp,      // 预测时间戳
    Double predictedHeat,       // 预测热度值
    Double confidence,          // 置信度
    List<String> reasons        // 预测理由（关键词、增速等）
) {}
```

## **五、核心算法设计（无代码）**

### **算法1：跨平台扩散检测**
**思路**：话题在知乎出现后，多久扩散到掘金？
- 记录`topic`首次出现时间戳（各平台）
- 计算时间差：`diff = juejinTime - zhihuTime`
- **判断**：`diff < 2小时` → 强扩散信号 → 预测加分

### **算法2：情感极化预警**
**思路**：原本中立的话题，突然负面激增
- 滑动窗口内计算情感分数**标准差**
- **判断**：`stdDev > 0.6` → 极化 → 可能爆发争议 → 预警

### **算法3：大V引爆点检测**
**思路**：万粉用户参与后，话题增速是否跃升
- 监测`influencerDensity`指标
- **判断**：`influencerDensity从0.05突增到0.2` → 引爆点 → 预测爆发

### **算法4：新关键词涌现**
**思路**：NLP提取TF-IDF，突然冒出新词
- 每日对比关键词词云
- **判断**："虚拟线程"这个词昨天出现0次，今天出现500次 → 新梗诞生
